# Описание

sn_router это минифреймворк для создания асинхронного HTTP или Websocket веб сервисов поверх Boost.Asio и Boost.Beast. Он использует маршрутизацию, похожую на Go Chi, что делает его очень простым и гибким в использовании

# Возможности

- Простая маршрутизация (как в Go Chi)
- Типобезопасные хендлеры
- Есть поддержка сериализации из json
- header only
- Поддержка глобальных и локальных промежуточных обработчиков (middleware)
- Поддержка HTTP/1.1 и Websocket
- Использование современного C++20

# Примеры

Простой роутинг по одному пути:

```cpp
#include "mux.hpp"

int main() {
    boost::asio::io_context io;
    auto m = sn::mux::create_mux(io);
    
    m.GET<"/">([](sn::response_type& res) {
        std::ostream(res.body()) << "Hello world!\n";
    });
    
    m.serveHTTP();
}
```

По умолчанию используется ip `127.0.0.1` и порт `8080`
